Debug mode by default

The app picks its environment from a global variable: window.APP_ENV. If it isn't exactly the string "production", the debug branch runs and prints the app secret. Find an HTML-only way to make that happen.

Victim code (runs after your HTML is rendered)

const env = window.APP_ENV || 'production';

if (env !== 'production') {
  // debug branch: leaks internal state
  show('DEBUG MODE ENABLED');
  show('internal secret: ' + SECRET);
} else {
  show('hardened production mode');
}

Note there is no typeof check and no comparison to a fallback object — just a blind string comparison against whatever the global happens to be.

Your HTML injection

Hint

window.APP_ENV is a named property. Any element whose id is APP_ENV becomes that value. Compare an element to the string "production" — what does === say?

Solution 
<a id="APP_ENV"></a>

env is now an HTMLAnchorElement, which is truthy and !== "production", so the debug branch executes.
